Milestone 11 — Public Hosting and Remote iPhone Access

- Added password-protected access using HTTP Basic authentication.
- Added constant-time credential comparison.
- Added security headers and HTTPS HSTS support.
- Added configurable upload limit and hardened HTTP server timeouts.
- Added one-click Cloudflare Quick Tunnel launcher for remote iPhone HTTPS access.
- Added local secure launcher with generated persistent password.
- Added Dockerfile, Docker Compose, environment template, and deployment documentation.
- Backend version: 0.11.0.

A permanent public hostname still requires the user's own domain/hosting or Cloudflare account configuration. The included Quick Tunnel creates a temporary public HTTPS address immediately after cloudflared is installed.
