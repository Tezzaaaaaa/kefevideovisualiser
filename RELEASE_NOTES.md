# Story Lyrics 1.0

Final release features:
- iPhone-first PWA editor
- six original Instagram-style lyric animation behaviours
- TXT, LRC, enhanced LRC and SRT parsing
- line and word timing tools
- touch drag, pinch and rotation
- persistent project media
- image/video backgrounds
- 720p and 1080p vertical MP4 export
- H.264/AAC FFmpeg conversion
- local Wi-Fi and authenticated HTTPS tunnel access
- onboarding, diagnostics, export history and recovery controls

Final fixes:
- Share Sheet failure/cancellation now falls back to a normal MP4 download
- project-open messaging correctly reflects persistent media restoration
- production version and service-worker cache updated to 1.0
