# Security and privacy

## Client-side edition

The GitHub Pages edition performs editing and rendering in the browser. Selected audio, lyric and background files remain on the device unless the user separately uploads or shares them.

## Reporting a problem

Do not publish passwords, tokens, private media, personal data or security-sensitive logs in a public issue. Describe the affected feature and reproduction steps without attaching confidential files.

## Supported deployment

The actively maintained public deployment is the client-side website in `docs/`. The older server-hosted files are retained for reference and should not be exposed publicly without reviewing authentication, upload limits and temporary-file handling.

## Content responsibility

Users are responsible for having permission to use imported music, lyrics, artwork and video. The project does not retrieve protected Apple Music media or bypass digital rights management.
