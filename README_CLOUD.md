# Story Lyrics Cloud 1.1

An iPhone-first lyric Story generator with Instagram-inspired lyric animation behaviours and server-side MP4 conversion.

## Included

- Responsive Safari/PWA editor
- Audio, lyrics, photo and video import
- TXT, LRC, enhanced LRC and SRT parsing
- Six lyric animation modes
- Touch positioning, scaling and rotation
- H.264/AAC MP4 export through FFmpeg
- Docker image
- Render Blueprint with HTTPS hosting and persistent disk

Read `CLOUD_DEPLOYMENT_GUIDE.md` for deployment.
